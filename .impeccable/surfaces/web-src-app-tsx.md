# React dashboard redesign

Mode: Operate. Target: login and all seven monitoring routes. Audience: individual node operators checking their own node. Preserve monitoring behavior, English/German, read-only access, local geography, exact amounts, and static Go embedding. Build code-first.

## Direction contract

THESIS: A precise protocol publication made operational: meaningful data, quiet rules, and legible hierarchy replace decorative dashboard tiles.

OWN-WORLD: Warm paper #f5f3ee, ink #202420, orange actions; charcoal #171817 and pale ink in dark mode. System sans, tabular data, monospace hashes, ruled flat sections, and native-feeling controls. Both themes share hierarchy.

STORY: Operators identify health and freshness, locate their connections, compare history, and inspect peers or blocks without losing context.

FIRST VIEWPORT: Desktop navigation left, with a toggle beside the brand for a remembered icon-only rail; localized hover titles and accessible names preserve navigation and sign-out. The mobile drawer keeps full labels regardless of the desktop preference. Status, language, theme, refresh above the workspace. The overview contains health, four key metrics, and a horizontal recent-block strip that opens actual blocks. Dedicated Mining and Node details routes join Peers, Traffic, Mempool, and Blocks. Mining begins with difficulty-period progress and the estimated next adjustment time, then a ruled pool-distribution section with its own block-window chooser, followed by the separate shared history range and hashrate/difficulty charts. Node details begins with synchronization and storage readings followed by inspectable Core information. Mempool opens with a ruled row of local conservative fee estimates for 2, 3, and 6-block targets, then existing mempool readings. Its shared range controls a full-width fee-estimate history plot before the existing activity charts; the exact data table preserves gaps and labels each target. Mobile stacks fee readings. Blocks keeps three status readings above one cursor-backed visual block browser with horizontal infinite scrolling and a native height search. Scrolling, touch, and paired arrow controls load 50-block pages in both directions; at most ten pages remain loaded, visible tiles render with four tiles of overscan, and page insertion or eviction preserves the visible block hash. Left/Right keyboard traversal can cross asynchronous page boundaries; Home/End and Tab reach loaded tiles. Height search accepts whole heights from genesis through the current tip, and a return-to-latest control announces new blocks. Indexing, the backfill frontier, pruning, offline and reorganization states remain explicit. A separate selected-block panel follows the browser and precedes economics; selected metadata and pool attribution persist when the selected tile leaves the loaded pages, while actual goggles and transaction details require a retained Core block. Closing restores the invoking tile control when it remains mounted. A two-column block-economics chart area follows this inspection panel. A native range select offers recent blocks, 24 hours, seven days, 30 days, one year, and all indexed history. Per-block stacked subsidy/fees, fee share, average/median fee rates, and fullness retain height order and exact BTC tables for recent blocks; historical time buckets show averages and block counts through expandable virtual tables. Unavailable statistics stay gaps, reward bars require both subsidy and fees, and partial indexing and stale data remain explicit. Mobile stacks the plots. The peer map, country distribution, transport breakdown, history, and searchable peer table live together on Peers. Mobile uses the same seven destinations in a navigation drawer, stacked work areas, and contained data overflow. Range filters precede history charts. Peers, expanded history data, and block transaction tables replace pagination with contained vertical scrolling, sticky headers, and a visible row count. Long lists render a measured window plus overscan; keyboard traversal and selected-row focus remain intact, search/sort reset the scroll position, and live refresh keeps it. Short tables remain fully rendered.

FORM: Protocol publication, grounded candidate 7, concept seed 517a1123; user selected it explicitly. Signature: the user-requested mempool-inspired block tiles share geometry between the overview's latest-ten strip and the Blocks page's historical browser, using geometric top and side faces within the incumbent paper/ink palette and open exact block details by hash. The selected block's static transaction mosaic sizes tiles by virtual bytes and colors them by fee-rate bands, with separate coinbase and unavailable-fee states. The persistent summary index stores headers, raw Core block statistics, and compact coinbase/pool evidence; its resumable whole-chain worker also serves mining distributions. Complete transactions and mosaic records are not archived. A wrapping pool-attribution row above the mosaic names the inferred miner or its availability state and matching method. Locally bundled official pool logos accompany names in this row and the mining distribution table, with light-theme variants where available and neutral fallbacks for unknown or missing logos; names and chart swatches retain their meaning without images. Tile selection and the initially collapsed, virtual-scrolling keyboard data table open inline transaction details with exact amounts and wrapping identifiers. No category filters. Familiar product navigation and controls outrank publication metaphor. Functional 180ms block-selection feedback; no decorative entrances.

Country distribution pairs each readable country name with a locally bundled SVG flag from flag-icons. Flags are small factual geography cues, not replacements for names or counts; unknown or unsupported country codes use a quiet globe. No external flag requests, changes to geography resolution, or chart-color changes.
